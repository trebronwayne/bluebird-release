What is Bluebird?

A launcher, styled
like a desktop.

Bluebird is a launcher — it runs as your Android home screen and gives it a desktop-styled layout: a taskbar, floating windows, a file explorer, and a small set of built-in apps.

Floating Windows & Taskbar

Apps open in resizable, floating windows with a taskbar and a start-menu-style app list — a desktop-style layout running entirely on your phone.

Works as Your Launcher

Set Bluebird as your default Android launcher and it replaces your home screen — no rooting needed.

Built-in App Suite

Comes with a file explorer, a terminal, a word processor, a media player, and an app store for small web-based (HTML/CSS/JS) apps.

Documentation

Installing & using Bluebird.

Getting Started

Install the APK, then set Bluebird as your default launcher from your Android settings.

Windows & Taskbar

Apps open as floating windows. Use the taskbar to switch between open apps and the start menu to launch new ones.

Built-in Apps

Bluebird ships with a file explorer, terminal, word processor, media player, and an app store for HTML/CSS/JS web apps.

Quick Start

# Step 1: Download the Bluebird APK from the Releases page
# Step 2: Install it via ADB or from your file manager

adb install bluebird-v2.2.apk

# Step 3: Set Bluebird as your default launcher
# Settings → Apps → Default Apps → Home App → Bluebird
About Bluebird

What Bluebird is.

Bluebird is an Android launcher — it replaces your home screen with a desktop-styled interface: floating windows, a taskbar, a start-menu-style app list, and a small built-in app suite.

Bluebird's source code is not publicly available. Release builds (.apk files) are published on GitHub.

Bluebird is downloadable and usable free of charge.

Privacy Policy

What Bluebird collects — and what it doesn't.

The Short Version

Bluebird does not collect personal data, telemetry, or analytics from within the app. It runs offline by default.

Your Data on Your Device
  • Files, settings, and app data within Bluebird stay on your device.
  • Bluebird does not sync or back up your data to any servers we operate.
GitHub & Third-Party Platforms
  • If you download Bluebird from GitHub or interact with the release repository, GitHub's own privacy policy applies to that interaction.
